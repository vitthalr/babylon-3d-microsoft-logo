# 3D Microsoft Logo

An interactive 3D rendering of the Microsoft logo built with [Babylon.js](https://www.babylonjs.com/).

## Live demo

👉 **https://vitthalr.github.io/babylon-3d-microsoft-logo/**

## Run locally

Open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Tech

- [Babylon.js](https://www.babylonjs.com/) loaded via CDN
- Vanilla HTML/JS, no build step required

## Project structure

- `index.html` – page and canvas setup
- `microsoftLogo.js` – scene, camera, lighting, and 3D logo geometry
